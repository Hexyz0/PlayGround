# Legacy build — The Hollow Crown (full tactical RPG)

This folder preserves the previous, much larger build of the game: 20 chapters, 24 jobs, a camp,
armoury, codex, and a grid battle engine.

It is not loaded by the current site. The root `index.html` now serves the simple, mobile-first
**Hollow Crown: Skirmish** game.

To run the old build, serve this folder as the web root:

```bash
cd legacy
python3 -m http.server 3003
```
